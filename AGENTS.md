## TOKEN EFFICIENCY

- Only inspect files relevant to the current task.
- Never scan the entire repository unless explicitly required.
- Read only necessary Memory Bank documents.
- Avoid repeatedly reading unchanged files.
- Avoid unnecessary tool calls and repeated explanations.
- Do not create multiple agents for simple tasks.
- Do not over-analyze straightforward changes.
- Use concise responses and concise command outputs.
- Stop when the requested task is completed and verified.
- Never sacrifice correctness or safety just to reduce tokens.
